# Hidden-property FEA transfer study

## Purpose

This workflow tests whether a response model trained on Dataset A can infer
unknown effective laminate properties from a small number of Dataset B FEA
observations, then predict the remaining Dataset B cases. Dataset B's material
scales are generated by the FEA configuration but are withheld from the
calibration objective. This is a synthetic FEA-to-FEA analogue of future
calibration against physical measurements; it is not physical validation.

## Modelled quantity and equivalent section properties

The beam is a straight, prismatic, 20-ply composite cantilever of fixed length
with constant width. A transverse point-load resultant is applied as equal
nodal forces along the free tip edge to avoid a single-node load singularity.
The output is the mean vertical displacement on that edge. The primary target
is compliance, $C=|\delta|/P$, so the fitted response can be rescaled by load
while the linear-static assumption holds.

For every FEA case the script records total laminate thickness, mass, and
laminate-level bending and transverse-shear stiffnesses:

\[
D_{\mathrm{eff}}=\text{CLT effective bending stiffness per unit width},
\qquad S_{\mathrm{eff}}=\sum_k G_{xz,k}t_k.
\]

The CLT bending stiffness is calculated from the full $ABD$ matrix, retaining
extension-bending coupling in the unsymmetric stack. It is converted to beam
rigidities using the case width $b$:

\[
EI=bD_{\mathrm{eff}},\qquad kGA=\kappa bS_{\mathrm{eff}}.
\]

At fixed length, these are the equivalent section properties used to predict
the net bending and shear contributions to tip compliance. Raw width, thickness,
layup property scales, $D_{\mathrm{eff}}$, $S_{\mathrm{eff}}$, $EI$, and $kGA$
are all retained in the case tables for traceability.

## Datasets and calibration

Dataset A contains 120 Latin-hypercube cases. It varies width, ply-thickness
scale, an in-plane modulus scale, and a transverse-shear modulus scale. The
20-ply carbon/glass sequence, length, boundary conditions, and load are fixed.
The two modulus scales apply to both constituent material cards, while density
and Poisson ratios remain unchanged.

Dataset B contains 12 width/thickness combinations using one hidden pair of
modulus scales. Its CSV contains known geometry and FEA responses but omits the
hidden scales; the separate `dataset_B_hidden_truth.json` is used only for a
post-calibration parameter-recovery audit. Four maximin cases are selected for
calibration, with the other eight kept out of model fitting and calibration.
At least two observations are needed to estimate two scales, and the default
uses four spread across width and thickness to improve identifiability.

Model A is a non-negative least-squares regression with FEA-fitted coefficients:

\[
\widehat{C}=c_b\frac{L^3}{3EI}+c_s\frac{L}{kGA},
\qquad c_b,c_s\geq0.
\]

This uses the beam mechanics scaling as regression features; it does not set
$c_b$ or $c_s$ to analytical values. Five-fold cross-validation on Dataset A
reports surrogate interpolation performance. Model A-1.0 predicts Dataset B
at nominal material scales $(1,1)$. Model A-2.0 is the same fitted regression,
with the two scales estimated by least squares on the four B calibration cases.
Final accuracy is scored only on the eight B holdouts, comparing nominal and
calibrated predictions to their FEA responses.

## Run

From the repository root, with project requirements, PyMAPDL, and a licensed
local MAPDL installation:

```powershell
python src/run_property_transfer_study.py `
  --stage all `
  --config config.hidden_property.example.json `
  --layup layup.json
```

`--stage all` launches Dataset A and Dataset B analyses and then calibrates and
validates. It runs 132 FEA cases at the mesh configured in the JSON. The stages
can be run separately with `--stage dataset-a`, `--stage dataset-b`, and
`--stage calibrate`. The calibration stage uses existing CSV results and does
not launch MAPDL. Use `--calibration-points` to vary the number of Dataset B
observations; at least two must be retained for the two fitted scales.

Default outputs are `results/property_transfer/dataset_A.csv`,
`results/property_transfer/dataset_B.csv`,
`results/property_transfer/dataset_B_hidden_truth.json`, and the fitted model,
metrics, and B predictions under `results/property_transfer/model/`.

## Scope and limits

- The ply sequence is fixed; this version varies effective in-plane and
  transverse-shear elastic properties, not material proportions, ply angles, or
  stacking order.
- Length, support, solver, element formulation, mesh, and load are held fixed
  between A and B. This isolates property calibration.
- A and B are both FEA datasets. Good holdout scores demonstrate transfer
  between the chosen FEA property settings, not agreement with physical test
  data or accuracy for a curved landing-gear leg.
- The section-equivalent bending/shear description relies on linear static beam
  behavior. Mesh convergence and the applicable small-deflection range should
  be checked before interpreting results.
