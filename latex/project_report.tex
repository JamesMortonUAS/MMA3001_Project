\begin{abstract}
This project demonstrates a workflow for fitting a finite-element-analysis (FEA) response model, calibrating it with a small number of observations, and testing predictions on withheld cases. The updated PyAnsys MAPDL model uses large-deflection static analysis for 80 training cases and 100 target cases across five sets. The fifth set adds a doubled resin-to-fibre ratio as an unmodelled composition shift. Three model classes are compared: a mechanics-informed compliance regression, a quadratic response surface, and a Gaussian process. Each target set uses three repeats of two-observation carbon/glass calibration with 18 held-out cases. This is an FEA-to-FEA methodology demonstration. The updated PyAnsys MAPDL workflow defines a large-deflection static experiment with 80 training cases and 100 target cases across five sets. The complete 180-case nonlinear dataset and model-validation results are not available for this submission, so that experiment is documented as a proposed computational study rather than reported as completed. Quantitative model results are from an earlier linear-static, four-set baseline and are explicitly labelled as historical. Those results show that two observations do not always identify two material corrections. The alternate-layup baseline used known configured material cards, not a blind unknown-material prediction. This study does not validate physical material properties or a curved landing-gear leg.
\end{abstract}

\section{Introduction}
Composite landing-gear design can require costly physical testing to determine how geometry, layup, and laminate stiffness affect deflection. This project investigates whether a model trained on FEA results can be corrected with only a few observations and used to predict unobserved responses. The long-term motivation is to apply the same workflow to physical test observations when they become available.

The present trial is a controlled methodology demonstration, not a landing-impact simulation or a mass optimization. It uses a straight cantilever as a tractable benchmark. No physical testing observations are included, and the material cards are numerical assumptions. Consequently, the validation performed here compares model predictions with held-out FEA results generated using the same modeling framework; it does not establish agreement with a manufactured gear.

\section{Finite-element model}
The beam is a flat rectangular layered shell with fixed length $L=0.25\,\mathrm{m}$. The axis is global $X$, width is global $Y$, and the applied transverse force is global $-Z$. The root edge is fully fixed. A total 10 N load is distributed equally across nodes on the free tip edge. The updated analysis is nonlinear static with large-deflection effects enabled using MAPDL \texttt{NLGEOM,ON} \cite{nlgeom}. Automatic time stepping is enabled with 10 initial substeps, a 1--100 substep range, up to 50 equilibrium iterations per substep, and full Newton-Raphson iterations. This accounts for geometric nonlinearity from large rotations while retaining the example's orthotropic linear-elastic material cards.

The mesh uses SHELL181 layered shell elements, with 40 divisions along the length and 6 across the width. Three through-thickness integration points are assigned per ply. This is a two-dimensional shell discretization with a layered section, not a three-dimensional solid model. All cases use the same mesh.

Dataset A uses a symmetric twill/glass stack built by repeating carbon twill (T) and glass (G) in the half-stack and mirroring about the mid-plane. Carbon twill plies are 0.20 mm and glass plies are 0.10 mm. Dataset B's alternate-layup set uses a symmetric repeating carbon UD (U), carbon twill (T), and glass (G) half-stack, truncated to the needed half-ply count and mirrored; both carbon ply types are 0.20 mm and glass is 0.10 mm.

Orthotropic elastic and shear properties are specified in the example configuration. For the transfer experiment, a carbon factor scales the elastic and shear moduli of carbon plies, and a glass factor scales those of glass plies; density, Poisson ratios, and ply thickness do not change when these factors vary. The cards and cured ply values are computational assumptions, not measured project material properties. For target Set 5 only, the resin-ratio proxy remixes the effective elastic and shear moduli using an assumed epoxy matrix modulus of 3.0 GPa and Poisson ratio 0.35. The configured baseline resin fraction is 50 vol%; doubling the resin:fibre volume ratio gives 66.7 vol% resin. Density and ply thickness are fixed, so this is a compliance-only proxy rather than a mass or physical resin-uptake model.

The response is tip compliance,
\begin{equation}
 C=\frac{|\bar{u}_{z,\mathrm{tip}}|}{P},
\end{equation}
where $\bar{u}_{z,\mathrm{tip}}$ is the mean vertical tip-edge displacement and $P=10\,\mathrm{N}$. Compliance has units of m/N. Under geometric nonlinearity, $C=|\delta|/P$ can depend on load; the model's valid load domain is therefore the fixed 10 N used consistently in both datasets. The case files also record effective section properties, mass, ply sequence, thickness, signed deflection, $|\delta|/L$, FEA wall time, and an analysis signature used to prevent incompatible results from being resumed.

\subsection{Inputs, outputs, and supported domain}
The configuration is a JSON file with SI units. Beam length, load, width, ply thickness, material moduli, and density must be positive and finite. The present training design uses a 0.25 m beam, 10 N load, widths 0.02--0.10 m, ply counts 8, 16, 24, and 32, and carbon/glass scale pairs $(1,1)$, $(1,2)$, $(2,1)$, and $(2,2)$. Target geometry cases use widths 0.015--0.15 m and even ply counts up to 100. Only symmetric \texttt{tw\_glass} and \texttt{ud\_tw\_glass} stacks made of zero-degree plies are supported. The output is mean vertical tip displacement in metres and compliance in m/N; the CSV also records mass, calculated section stiffnesses, design identifiers, nonlinear-analysis metadata, and elapsed time.

Missing required configuration sections, unsupported stack names, odd or out-of-range ply counts, invalid material cards, nonpositive model predictors, or disabled large-deflection/time-stepping settings cause a clear exception before MAPDL is launched. The current model does not accept a load range, nonzero ply orientations, damage/failure models, or arbitrary material families. Changing load or the FEA definition requires a fresh analysis dataset and model fit; stale linear-static CSVs are rejected by the new case-signature check.

\section{Experiment design and data}
\subsection{Dataset A: model training}
Dataset A contains the full 5 by 4 by 4 factorial design: five widths, four ply counts, and four carbon/glass property-factor combinations. The combinations are $(1,1)$, $(1,2)$, $(2,1)$, and $(2,2)$.
\begin{itemize}
\item Widths: 0.02, 0.04, 0.06, 0.08, and 0.10 m.
\item Ply counts: 8, 16, 24, and 32.
\item Carbon/glass stiffness factor pairs: $(1,1)$, $(1,2)$, $(2,1)$, and $(2,2)$.
\end{itemize}
This gives 80 FEA responses. The training cases span the base twill/glass stack and the configured carbon/glass stiffness variation.

Set 5 deliberately changes a third material attribute that the correction model does not fit. Its target FEA cards use a two-times resin:fibre ratio, while nominal and calibrated surrogate features assume the baseline ratio. The two observations still fit only carbon and glass stiffness multipliers; the validation therefore measures whether those corrections absorb an unmodelled resin-rich shift, not whether the resin ratio is identified. The matrix modulus is based on typical cured tensile modulus in the Westlake EPIKOTE LR285 technical data sheet; the matrix Poisson ratio and the 50% baseline fraction for glass are illustrative assumptions. The 50% resin baseline for twill is consistent with the midpoint of a cited woven-carbon laminate fibre-volume range.

The layup-transfer case is important to interpret correctly. Its FEA targets were generated with the material cards in the configuration at factors $(1,1)$. Those same configured cards and the known alternate ply sequence were used to calculate nominal laminate section properties for prediction. Thus nominal predictions were not made with no material knowledge: this set tests transfer to a different layup using known nominal material cards. During calibration, the model was allowed to adjust the carbon and glass factors around that baseline using only response observations. The configured truth factors were not supplied to the calibration optimizer.

\section{Models, calibration, and validation}
\subsection{Section-property predictors}
For each case, the effective laminate bending rigidity per unit width $\Dref$ is calculated from the laminate stiffness matrices. The transverse-shear rigidity per unit width is approximated as
\begin{equation}
 \Sref=\sum_k G_{xz,k}t_k.
\end{equation}
For a case of width $b$, the bending and corrected shear rigidities are $EI=b\Dref$ and $kGA=\kappa b\Sref$, with $\kappa=5/6$. The mechanical basis terms are
\begin{equation}
 x_b=\frac{L^3}{3EI}, \qquad x_s=\frac{L}{kGA}.
\end{equation}

\subsection{Model families}
Three models are fit to Dataset A only:
\begin{enumerate}
\item \textbf{Mechanics-informed compliance regression:} nonnegative, no-intercept least squares in $x_b$ and $x_s$, $\widehat C=\beta_bx_b+\beta_sx_s$.
\item \textbf{Quadratic response surface:} second-order polynomial in standardized logarithms of width, total thickness, $\Dref$, and $\Sref$, fit to log compliance with ridge regularization.
\item \textbf{Gaussian process:} Mat\'ern 5/2 kernel plus a white-noise term, using the same log predictors and log compliance.
\end{enumerate}
Five-fold cross-validation on Dataset A estimates within-training-domain predictive performance. Target FEA responses are not used to fit or select the Dataset A models. The mechanics-informed linear bending/shear basis is retained as a transparent baseline; it does not model large-rotation kinematics and is not an exact nonlinear beam solution.

\subsection{Calibration and held-out validation}
For each of the five target sets, three calibration repeats are performed. A pair of target cases is randomly selected for each repeat; the same pair is used across model families. For each fitted model, nonlinear least squares estimates two multipliers, $q_C$ and $q_G$, by minimizing the squared log-compliance residuals at the selected cases:
\begin{equation}
 (q_C^*,q_G^*)=\arg\min_{q_C,q_G}\sum_{i\in\mathcal C}
 \left[\log\widehat C_i(q_C,q_G)-\log C_{i,\mathrm{FEA}}\right]^2,
 \qquad |\mathcal C|=2.
\end{equation}
Candidate factors are applied to the configured ply material cards, after which $\Dref$, $\Sref$, $EI$, and $kGA$ are recalculated. The trained model coefficients or surrogate surface are held fixed. The compliance observations are the calibration data; calculated section properties are model inputs, not target observations.

The other 18 cases are held out for validation in each repeat. The calibration cases do not appear in the validation metrics. Reported measures include MAPE, maximum absolute percentage error, RMSE, and $R^2$. Calibration fits two unknown factors from the algebraic minimum of two observations, so a poorly chosen pair may produce non-identifiable or unstable factors. Jacobian rank and condition number are recorded. Runtime is measured separately for each FEA case, model fit, five-fold cross-validation, and target calibration/prediction; these timings are machine-specific and are saved with the outputs.

\section{Discussion and limitations}
The results show that a small number of observations can correct a response model when the target variation is represented by the calibration parameters and the selected observations are informative. They also show that low Dataset A cross-validation error does not guarantee robust target calibration. Calibration pair selection matters: two response measurements should produce distinct sensitivities to the unknown property factors. A high Jacobian condition number or deficient rank signals that the fitted factors should not be interpreted.

The alternate-layup and geometry-extrapolation cases had low nominal MAPE because their configured section properties were available and close to the training response domain. Calibration brought little benefit there and sometimes increased error by adjusting the property factors to absorb small model residuals. This is consistent with a correction method that should be applied only when justified by observations and diagnostics.

The updated geometric-nonlinear analysis is intended to account for large rotations at the configured 10 N load. The prior linear-static run had a maximum target $|\delta|/L$ of 1.70 (21/80 target cases and 22/80 training cases exceeded 0.1); those old displacements and compliance values are not evidence for the new nonlinear formulation. Large rotations do not address material nonlinearity, laminate failure, progressive damage, contact, or landing-impact dynamics. Because compliance is load-dependent in this model, these predictions are restricted to the fixed 10 N case unless new load-level data are generated and included in training.

All cases in the updated design use a 40 by 6 mesh. A complete nonlinear dataset with solver-convergence records and model-validation metrics is not available for this report. Therefore, no performance or runtime claim is made for that formulation. A future execution should verify mesh sensitivity, reaction balance, element orientation, supports, load application, nonlinear convergence histories, and possible locking. The reported historical results do not address impact dynamics, failure, progressive damage, manufacturing constraints, or curved landing-gear geometry.

\section{Conclusion and next steps}
The historical linear-static trial implemented the training-calibration-validation workflow and compared three surrogate types. The updated runner defines a nonlinear large-deflection static formulation, explicit input checks, case-signature protection against stale output reuse, and runtime instrumentation. Since a complete nonlinear dataset is unavailable, its fit, calibration, validation, and computational cost cannot be assessed here. The historical trial showed that nominal predictions require a baseline material description and that calibration observations must identify the unknown factors. Its new-layup subset used known configured properties; it was not a no-material-knowledge test.

Next, generate all 180 cases with large-deflection analysis enabled. Review solver convergence and force/reaction balance, then fit all three models and report validation and timing results. Select calibration pairs by maximizing sensitivity separation and verify mesh convergence for representative cases. A subsequent study can introduce observations from a trusted analytical model or physical testing. Applying the method to curved gear geometry and optimizing mass/stroke are future extensions, not outcomes of this trial.
